# 주택청약지도

대한민국의 행정구역을 시·도 → 시·군 → 구 순서로 탐색하는 반응형 점묘 벡터 지도입니다.

## 실행

별도 설치나 빌드 없이 `index.html`을 직접 열 수 있습니다. 로컬 서버로 실행하려면:

```bash
python3 -m http.server 4173
```

그다음 브라우저에서 `http://localhost:4173`을 엽니다.

## 기능

- 17개 시·도 단위 벡터 지도
- 시·도 클릭 후 시·군·구 단위 드릴다운
- 수원·성남·고양·용인 등 일반구가 있는 도시의 `시 → 구` 추가 단계
- 클릭한 지역으로 부드럽게 이동하는 SVG `viewBox` 확대 애니메이션
- 확대 비율에 맞춰 밀도를 유지하는 순수 SVG 점 패턴
- 기본 회색 점, 호버 시 검정색 전환과 확대, 비호버 지역 감쇠
- 검정색 커서 추적 점, 툴팁 및 글로우 모션
- 클릭한 지역의 파란색 활성 상태 유지
- 키보드 탐색과 모바일 터치 지원
